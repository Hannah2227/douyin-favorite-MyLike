# M5 收藏与账号扩展

对应 PRD v1.17，版本 0.7.0，2026-10-23。本期仅 Windows x64。

## 行为与数据

- 放大自动采集按钮和续播栏，统一左栏主题、常见问题、使用教程、项目入口；帮助离线可用，项目地址由系统默认浏览器打开，移除左栏版本号。
- 左栏可直接改名、删除账号，显示“本地自定义名(抖音名)”。删除需确认，清理该账号的当前记录、会话、缓存和应用历史备份中的记录；保留其他账号与共享作品，不创建删除前备份。损坏或占用的备份阻止成功，应用外文件由用户管理。
- 收藏作品、收藏夹与夹内关系独立于喜欢，复用作品元数据；SQLite v6 升级前保留一致性 v5 备份。任务按全部收藏 → 收藏夹列表 → 各夹作品顺序分页，由真实页面 SDK 处理请求，不引入本地签名。
- 页面、精确游标与分类在同一事务提交；重启暂停，手动续采；收藏夹和夹内旧关系分别在完整返回后清理，异常页不清空旧分类。限流暂停，网络仅有限重试。喜欢采集、收藏同步与取消点赞互斥，播放取链优先。
- 按夹搜索与播放使用固定队列；收藏页和收藏队列不显示取消点赞，不提供远端收藏编辑、收藏导入导出。仪表盘对喜欢 / 收藏去重统计。

## 验证

63 项单元测试通过，包含来源与账号隔离、长 ID / 游标、事务回滚、异常空夹、重启精确断点、v5 升级后喜欢与队列保留，以及当前库和 v5 / v6 历史备份中删除账号后其他账号与共享作品保留。额外确认取消点赞成功不会删除收藏及夹内关系；损坏备份阻止删除当前账号。

开发构建四项定向 Electron 场景通过：按钮 / 续播栏尺寸、帮助 / 项目入口与账号改名；收藏夹分页、暂停重启与按夹播放；限流无盲重试；删除账号同时清理历史备份。系统浏览器调用被测试拦截。

生产包截图：[喜欢库与左栏](m5-library-0.7.0.png)、[按收藏夹浏览](m5-favorites-0.7.0.png)。截图内容为隔离测试样本，不含用户数据。

0.7.0 单 EXE 自解压、首次启动、SQLite、账号 / 主题保存、退出及重启通过；EXE 与 ZIP 的 7zip 完整性通过，EXE 有启动器尾部数据提示。EXE 为 101,792,630 字节，ZIP 为 157,232,394 字节，尚未发布 Release。

类型、格式检查与完整 **45 项 Windows x64 生产包桌面回归全部通过**，包括新增三项收藏 / 帮助场景、删除账号清理备份，以及既有采集、媒体、全屏、导入导出和崩溃恢复。5 万条喜欢库生产包查询首次 190ms、p95 97ms，仅代表本机这组数据。最终代码之后只更新了文档与截图，未修改发行文件。

真实账号收藏 / 收藏夹接口、Edge / Chrome 实际打开和干净 Windows 环境尚未验收；本轮未操作真实账号或发出真实取消点赞请求。既有 15 分钟连播和内存记录仍见 M4，本轮没有新增长时或内存结论。
