# 管理与发行阶段记录

2026-10-22 · MyLike 0.6.1 · Windows 生产包回归、主题与原页入口调整通过，用户确认真实取消点赞正常；各版本记录如下。

- 账号本地别名、退出登录、移除前备份；只清理目标 Session，其他账号及共享作品保留。备份失败不清理认证或数据。
- JSON v1 元数据导出固定筛选或选择快照；导入先预览、备份、事务合并。本地元数据优先，取消预览不写入。格式与恢复见 [说明](../data-format.md)。
- 导出原子替换，失败清理临时文件；拒绝应用数据目录及其目录别名。导入限制 10 万条 / 64 MiB，校验 UTF-8、版本、字段及字符串 ID，不导入认证与临时链接。
- 取消点赞在实际平台页执行固定 POST，由页面 SDK 处理；逐条核对账号并持久记录。成功与本地移除同事务，未知保留条目且阻止重复写。停止和正常退出等待当前请求，启动后不自动继续；只读核验可消除未知状态，仍点赞时必须重新选择确认。
- 导入成员须先核验当前点赞状态；导入不作为增量扫描重合或当前点赞的证明。代理执行的真实账号验收保持只读；用户随后自行完成取消点赞验收并反馈正常，未据此推断所有异常场景均已在真实平台验证。
- 数据库升级到 v5 前备份，保留既有 Electron 数据、播放队列与 Session；不迁移旧 WPF 数据。

## 0.5.1 异常恢复与持续播放

新增四项实际 Electron 故障测试：强制结束测试应用进程树后，采集保留已提交页与精确游标、重启等待手动继续；未确认写入变为未知，阻止重复创建，只继续未发送项；数据库快速检查与外键检查正常。测试只终止经数据目录核验的临时应用进程，不操作用户实例。

复现并修复抖音引擎崩溃被记成普通取消的问题，使用独立原因暂停任务；关闭崩溃窗口不再把失效渲染进程标回就绪，手动继续时重建引擎。崩溃期间未确认写入仍为未知，迟到响应不能改成成功或触发重发。开发构建四项故障用例通过；51 项单元、37 项整组生产回归通过，最终关闭窗口修正后另通过 8 项相关生产包复验，覆盖普通取消、登录、引擎重建、导航与故障恢复。类型、格式、最终 EXE 启动重启及 EXE / ZIP 完整性检查通过。最终 EXE 为 101,782,350 字节，ZIP 为 157,217,172 字节；没有发送真实取消点赞请求。

另用 **0.5.0 生产包的临时副本**完成 15 分钟视频连播，未连接调试器，隐藏窗口且关闭后台节流；5 万条固定队列，末次采样已切到索引 167，30 次采样均有实际解码，无卡死或解码错误。媒体区始终一个视频元素，内容库最多 25 张卡片，播放阶段进程数为 6。测量入口加入 90 秒无进度失败检查，并适配新的返回按钮；源 EXE / ASAR 未修改。[原始脱敏数据](m4-soak-0.5.0.jsonl)。
