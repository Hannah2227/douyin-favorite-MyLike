## 0.8.1 交互精简

对应 PRD v1.19。删除复制作品链接的 UI 与 IPC、播放器快捷键帮助、侧栏展开入口及无用样式。设置仅保留用户截图中的 12 项绑定，上下键与 PageUp / PageDown 切作品，左右键按媒体类型快进退或手动翻图；倍速循环为 0.75 / 1 / 1.25 / 1.5 / 1.75 / 2，默认不绑定，原页也默认不绑定。Esc 保留为退出全屏 / 返回，不进入绑定选项；取消点赞仍需确认。键位设置增加版本标记，旧默认键升级，仍支持的自定义键保留，已移除动作不再占用按键。
