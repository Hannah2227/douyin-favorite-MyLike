# MyLike Electron 0.8.3 · Windows 预览版

这是首次公开发布的 Electron 重构预览版，采用 Electron + TypeScript + React + SQLite。本期仅支持 Windows x64；版本号独立于旧 WPF 版，标签为 `electron-v0.8.3`。

## 可以做什么

- 采集自己的喜欢，支持增量、断点、暂停和继续；同步收藏作品与收藏夹，按夹浏览。
- 搜索标题 / 作者、筛选类型与年月、触底自动加载；仪表盘展示内容统计、发布年份和最近收录。
- 播放视频、图集和实况，支持顺序 / 洗牌、续播、倍速、全屏、常驻队列和设置中的 12 项快捷键。
- 管理多个账号，改名、退出登录或删除；删除会清理应用历史备份中的该账号数据。
- 整理本地喜欢元数据、JSON 导入导出、备份和缓存清理；确认后逐条取消点赞，未知结果不自动重发。
- 后台采集或取消点赞时继续看视频；提供深浅主题、界面缩放、窗口记忆和本地帮助。

## 下载

- `MyLike-0.8.3-win-x64-portable.exe`：双击运行，启动时解压，无需安装额外运行时。
- `MyLike-0.8.3-win-x64.zip`：完整解压后运行 `MyLike.exe`。
- `SHA256SUMS.txt`：两种安装包的 SHA-256 校验值。

程序未签名。用户数据位于 `%APPDATA%\MyLikeElectron`，独立于程序文件，更换程序位置不会改变该目录。**旧 WPF 版 `.dylist`、数据库和浏览器登录态不兼容、不迁移**，首次使用需重新登录与采集。

## 验证与限制

本机 Windows 11 x64 已验证生产包与免安装 EXE 启动、退出和重启，归档完整性及 `app.asar` 一致性通过。发行前 69 项单元测试和 57 项完整生产包桌面回归全部通过（14.9 分钟），覆盖采集、播放、收藏、账号、数据管理及写结果未知后的恢复；详细结果见 [M6 验收记录](https://github.com/Hannah2227/douyin-favorite-MyLike/blob/electron-v0.8.3/docs/evidence/M6.md)。

真实身份、喜欢采集、三类媒体和续播已有验收，用户确认真实取消点赞正常。**收藏作品及收藏夹仍待真实账号只读验收**，受控测试通过不代表平台长期兼容。干净 Windows 机器、真实人工验证恢复和数小时混合运行仍未完成；macOS / Linux 延期。平台限制或接口变化可能导致暂停或需要更新。

本版保存元数据，不提供媒体完整下载或离线播放；收藏首期只读且不提供导入导出。外部浏览器与应用使用独立登录态。
