# 元数据文件与恢复

喜欢库导出为 UTF-8 JSON，`format` 为 `mylike.library`、`version` 为 `1`。只接受此版本，一次最多 10 万条、64 MiB；不读取旧 WPF 格式。收藏及收藏夹首期不提供导入导出。

```json
{
  "format": "mylike.library",
  "version": 1,
  "exportedAt": "2026-10-22T00:00:00.000Z",
  "source": { "label": "我的列表" },
  "items": [{
    "id": "7381234567890123456",
    "title": "作品标题",
    "author": "作者",
    "publishedAt": 1700000000,
    "mediaType": "video",
    "isLive": false,
    "collectedAt": 1700000000000
  }]
}
```

作品 ID 必须是数字字符串，发布时间为 Unix 秒，收录时间为 Unix 毫秒。媒体类型为 `video` / `gallery`，只有图集可标记 `isLive`。文件不含账号身份、Cookie、封面、临时媒体链接或采集断点；未知字段、错误类型和不支持的版本直接拒绝。

导入先预览，确认后创建一致性备份，再事务合并到所选账号。文件内同 ID 保留第一条；本地已有作品元数据优先，已有成员的收录时间保留。失败整批回滚，取消预览不修改数据。导入不改变账号绑定或采集断点，也不证明当前账号已点赞；首次实际采到后才标记为平台收录。

导出固定当前筛选或选择快照，先写临时文件再原子替换目标。应用数据目录及其目录别名不可作为导出位置。数据库备份另存于数据目录的 `backups/*.sqlite`，不含浏览器会话；备份包含已提交的 WAL 内容。

从 0.7.0 起，删除账号会清理当前数据库和应用历史备份中的该账号、成员关系、任务及播放记录，不再生成删除前备份；其他账号及仍有引用的作品保留。应用外的导出文件、用户另行复制的备份不在清理范围内。退出登录只清理登录态，保留本地记录。

确需恢复时先退出 MyLike，并另存整个当前数据目录。在应用完全退出的情况下，将所选备份复制为数据目录中的 `mylike.sqlite`，移走同名 `-wal` / `-shm` 后再启动。不要在运行期间覆盖数据库；更高版本的数据库不能交给旧版程序打开。恢复数据库不会恢复已清理的登录态，也不会撤销已发生的远端操作。
