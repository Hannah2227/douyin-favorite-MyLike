# MyLike Electron

Electron 重构工程，需求统一维护在 [PRD](../../docs/PRD.md)。当前为 **0.8.3 开发预览**，本期仅支持 Windows x64，macOS / Linux 延期；生产包验收记录见 `docs/evidence`。

## 开发与验证

在本目录使用 Node.js 24.12+、pnpm 11.22：

```powershell
pnpm install --frozen-lockfile
pnpm exec electron --version
pnpm dev
```

```powershell
pnpm format:check
pnpm test
pnpm build
pnpm test:e2e
pnpm package:win
$env:MYLIKE_EXECUTABLE = Join-Path $PWD 'dist/win-unpacked/MyLike.exe'
pnpm test:e2e
node tests/portable-smoke.mjs
```

`pnpm package:win` 生成 `dist/MyLike-0.8.3-win-x64-portable.exe` 和 ZIP 解压版；目录版可运行 `dist/win-unpacked/MyLike.exe`。依赖随包分发，无需安装 Node.js 或 WebView2。单 EXE 每次先解压运行文件到临时目录；用户数据独立保存。应用图标源为 `assets/icon.svg`，修改后运行 `pnpm icons` 生成透明 PNG 与多尺寸 ICO；图标生成使用隔离临时 Chromium 目录。

打包工具初次使用需要下载。`pnpm-workspace.yaml` 针对 electron-builder 26.15.3 声明的下载库版本不匹配，固定其 `@electron/get` 为 4.0.3；保留 TLS 与校验和检查。GitHub 不可达时可在当前终端指定受信镜像的 `ELECTRON_BUILDER_BINARIES_MIRROR`，无需修改项目或关闭校验。

## 当前可以做什么

- 添加、重命名、切换、退出登录与删除账号；左栏提供改名与删除，名称显示为“本地自定义名(抖音名)”。删除须确认，清除当前数据、登录态与缓存，并从应用历史备份中清理该账号；不生成删除前备份，保留其他账号与仍被引用的共享作品。外部导出文件由用户管理。深浅主题和播放偏好独立于账号。
- 打开抖音登录窗口并核验身份；自动检查新增和补齐深层断点，暂停 / 继续 / 停止，重启后手动恢复。
- 采集每页事务保存，网络故障至多重试两次，限流 / 验证 / 异常页保留原因并暂停；每 8 页或 3 分钟在页间回收隐藏引擎，休息后自动接续。
- 强制退出后恢复已提交断点，等待手动继续；抖音页面崩溃单独报告，未确认的取消点赞记录为未知，不自动重发。
- 独立“收藏的内容”入口，同步本人收藏作品、收藏夹与夹内作品；支持按夹搜索、筛选、顺序 / 洗牌播放。数据来源与喜欢分开，断点逐页保存，暂停后或重启后手动继续；完整返回某夹后才清理过期分类关系。首期只读，不修改远端收藏，不提供收藏导入导出。
- 喜欢采集、收藏同步或后台取消点赞时都可浏览、播放和切换作品；页面请求串行，取链优先于下一后台项，当前写请求会先保存结果。三个后台任务互斥，单页诊断和手动释放仍可使用。
- 顶部搜索标题 / 作者，筛选栏提供类型、年月与顺序 / 洗牌播放；固定按发布时间倒序，移除排序下拉和装饰文案。喜欢、收藏及收藏夹触底自动追加下一页，保留虚拟化和滚动位置；加载失败保留已有内容并显式重试，隐藏页面不自动翻页。固定批量选择，本地删除保留远端点赞。
- 独立仪表盘保留内容统计、按作品发布年份统计数量（喜欢与收藏去重）、继续播放和最近收录；移除任务动态与内容来源，回看和年份分布并排。元数据占用是全部账号共用文件（不含缓存与备份）；概览不受内容库筛选影响，回看使用完整账号内容。
- “连接与任务”采用紧凑账号连接区和三个固定任务块，直接展示进度、异常及暂停 / 继续 / 停止；移除统一任务表与筛选。取消点赞逐条记录按需展开，未知结果自动展开，保留最近 50 项历史和只读核验；诊断与运行记录合入底部折叠区。
- 设置按通用、播放、快捷键、账号、数据与存储、关于分组并支持搜索。可设置启动页、界面缩放、窗口记忆、减少动画、自动播放、滚轮切换、失焦暂停、快进步长、音量与倍速。支持分组恢复默认、只读数据库检查、复制脱敏诊断与查看发布记录；不在启动时自动继续后台任务。
- 自动采集顶栏按钮仅在喜欢库显示，放大按钮与续播栏文字。主题切换位于左栏账号上方，下方依次为常见问题、使用教程和项目地址；帮助内容可离线查看，项目地址交给系统默认浏览器，左栏不再显示版本。系统窗口按钮随主题变化，播放页保持深色。账号、收藏夹、年月、主题、快捷键和历史任务使用统一下拉菜单，支持键盘与小窗口定位。
- 同窗口播放视频、静态 / 实况图集和音乐；进入时左栏收起，作者、日期与可展开文案浮在画面底部，主要控件在紧凑底栏。左右翻图、纵向倍速菜单及悬停高亮进度条；播放队列跨作品保持展开，手动关闭，列表顶部避开系统窗口按钮，兼容窗口缩放、最大化与全屏。
- 窄顶栏合并窗口拖动区并浮在画面上，底栏紧凑，播放 / 暂停与切换按钮使用一致的透明底。关闭连播时循环当前作品；静态图每张 3 秒，实况播完显示对应静态照片 2 秒；手动翻图停留，可恢复轮播。全屏容器跨作品保留；返回内容库淡入淡出，保留搜索、筛选与滚动。原页看评论在系统默认浏览器打开，应用暂停并保存位置，返回后手动继续；浏览器登录态独立。支持续播和自定义快捷键。
- 横竖媒体均在剩余区域内保持比例、完整居中；左栏展开或页面缩放时底部控件按实际宽度换行，媒体固有尺寸不会撑大页面。
- 播放快捷键仅保留 12 项，在设置中管理。默认空格播放 / 暂停、上下键或 PageUp / PageDown 切条、左右键快进退或翻图、Q 队列、F 全屏、N 静音、A 连播、Z 取消点赞确认；倍速循环（0.75x–2x）和原页默认不绑。Esc 退出全屏或返回，输入 / 菜单 / 弹窗优先；移除复制链接、播放页快捷键帮助和展开左栏。旧默认键升级，仍支持的自定义键保留。
- 主界面标题栏空白与标题、左栏品牌及顶部留白可拖动窗口；搜索和按钮正常交互。播放器只在窄顶栏空白处拖动，全屏禁用窗口拖动。
- 版本化 JSON 元数据导入导出、预览后事务合并、一致性备份、缓存清理和占用诊断；格式与恢复见 [说明](../../docs/data-format.md)。
- 播放中单条、列表批量取消点赞，逐条记录并保存成功结果；可停止未发送项，未知结果保留本地记录且不重发，只读核验后再决定下一步。

真实只读验收已完成身份核验、三类媒体及音乐播放、重启续播和早期内置原页恢复；采到平台返回末尾后本地 397 条，再次重扫 21 页新增 0 条，期间自动回收引擎。用户已反馈真实取消点赞正常。收藏及收藏夹仍需真实账号只读验收，受控测试见 [M5](../../docs/evidence/M5.md)。0.8.3 发行前的 69 项单元、57 项完整 Windows 生产包回归（14.9 分钟）、免安装启动重启及归档一致性检查通过，界面截图及限制见 [M6](../../docs/evidence/M6.md)。外部浏览器、真实人工验证恢复、长时间稳定性和其他系统分别记录，不能视为全部通过。

内存实测见 [M0 记录](../../docs/evidence/M0.md)，不能按早期估算判断。`pnpm build` 后可手动运行 `node tests/platform-benchmark.mjs`：使用编译产物、独立匿名会话且不连接调试器，观察引擎运行和释放后的内存。`node tests/platform-smoke.mjs` 则观察生产目录包的请求流程，带有 Playwright 调试连接，其内存数值不能直接当作常规运行基线。两者仅发送匿名只读请求，不打印签名值或 Cookie。

## 代码边界

| 目录 | 职责 |
| --- | --- |
| `src/main` | 生命周期、受限 IPC、账号 / 喜欢采集 / 收藏同步 / 取消点赞 / 数据管理服务与请求通道 |
| `src/main/douyin` | 独立会话与页面引擎、单次请求、平台响应解析 |
| `src/main/storage` | 数据库 worker、事务、查询、队列、任务记录与文件合并 |
| `src/preload` / `src/shared` | 最小桥接、命令与数据契约 |
| `src/renderer` | React 内容库、连接面板、播放器与设置 |
| `tests/unit` / `tests/e2e` | 临时真实数据库、受控平台与 Electron 集成验证 |

Windows 默认数据在 `%APPDATA%/MyLikeElectron`，不访问旧版数据或会话目录。自动化测试用 `MYLIKE_USER_DATA` 指向独立临时目录，用 `MYLIKE_HEADLESS=1` 隐藏窗口；自动化测试不会登录或操作真实账号。人工配合的真实验收使用该版本自己的持久会话和数据库。

现有 Electron 数据库升级到 v6 前，使用 SQLite 一致性快照写入 `backups/before-v6-*.sqlite`，保留 WAL 中已提交的数据；失败时停止升级，不重置数据库。已有会话不清理。请勿让旧版程序打开升级后的数据库。删除账号还会清理应用备份中该账号的记录；损坏、占用或不受支持的备份会阻止删除成功，不应通过恢复旧备份找回已删除账号。
